LEDGER ENTRY — 03.5

How a Single Click Moves Through the System

Every module above reads and writes the same live Firestore database — there's no batch job, no nightly sync. The moment payroll runs, the payslip, the analytics chart and the audit log update in the same instant. Here's the actual path a single action takes:

01 · Action
A role takes an action
HR runs payroll, a manager approves leave, an employee checks in — any of the 41 modules.
→
02 · Rules
Firestore Security Rules check
Every write is checked against the 4-tier role system before it's ever accepted.
→
03 · Store
Firestore updates the record
One canonical document is updated — no duplicate copies drifting out of sync.
→
04 · Push
Live listeners push it out
Every open screen watching that data (onSnapshot) redraws itself in real time — no refresh needed.
→
05 · Trail
Audit log records it
Who, what, when — permanently logged for compliance, visible to Admin and HR.
